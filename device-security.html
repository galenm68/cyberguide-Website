Device Security

Protect the Devices That Connect You to the World

Your phone, computer, and other connected devices contain a lot of personal information. Keeping them secure can help prevent unauthorized access, malware, data loss, and other problems.

Keep Your Devices Updated

Updates Are More Than New Features

Operating system and app updates often include important security fixes. Delaying updates can leave known vulnerabilities unprotected.

Make Updates a Habit

  • Turn on automatic updates when available.
  • Install updates for your operating system, apps, browsers, and security software.
  • Restart your device when an update requires it.
  • Don't ignore repeated security update notifications.
  • Replace devices that no longer receive security updates when practical.
Quick Tip: If your device says an update includes a "security fix," don't put it off.

Antivirus & Security Software

Give Your Device Another Layer of Protection

Antivirus and security software can help detect, block, and remove malicious software. Many modern devices already include built-in security features, so you may not always need additional software.

Good Security Practices

  • Keep your security software enabled and updated.
  • Use security tools that come from reputable providers.
  • Don't install multiple antivirus programs unless you know they are designed to work together.
  • Pay attention to security warnings and alerts.
  • Run a scan if you notice unusual device behavior.
Quick Tip: If your device says an update includes a "security fix," don't put it off.

Be Careful of Fake Antivirus

Some websites display scary pop-ups claiming that your device has been infected and asking you to download software or call a phone number.

Don't Panic. Don't Click.

Close the page and use your device's legitimate security tools to check for problems.

Be Careful With Downloads

If You Didn't Expect It, Don't Download It

Malware can hide inside applications, documents, browser extensions, and other files. Downloading something from an untrustworthy source can put your device and information at risk.

Before Downloading

Use Trusted Sources

Download apps and software from official app stores or the developer's legitimate website.

Check the file

Be cautious with unexpected attachments and unfamiliar file types.

Avoid pirated software

Cracked applications and unauthorized downloads can contain malware.

Read before clicking

Don't automatically click "Download" on a website. Some pages contain misleading advertisements designed to look like download buttons.

Remember: Free doesn't always mean safe.

If you weren't expecting a file or don't recognize where it came from, don't open it.

Public Wi-Fi

Convenient Doesn't Always Mean Secure

Public Wi-Fi is useful at airports, restaurants, hotels, libraries, and other locations, but you shouldn't automatically assume that every network is trustworthy.

When Using Public Wi-Fi

  • Confirm the network name with the business.
  • Avoid accessing highly sensitive accounts when possible.
  • Don't enter sensitive information on suspicious websites.
  • Turn off automatic connection to unfamiliar networks.
  • Disconnect from the network when you're finished.
  • Use a more trusted connection when possible.

Watch for Fake Networks

Attackers can create Wi-Fi networks with names that look similar to legitimate ones.

For Example:
CoffeeShop_Guest 🟩
CoffeeShop_Free_WiFi 🚩

If you're unsure which network is legitimate, ask an employee before connecting.

Backups

Prepare for the Unexpected

A device can be lost, stolen, damaged, or infected with malware. A backup gives you another copy of important files so you don't lose everything if something happens to your device.

What Should You Back Up?

Consider backing up:

  • Important documents
  • Photos and videos
  • School or work files
  • Financial records
  • Other files that would be difficult or impossible to replace

Follow the 3-2-1 Approach

A simple backup strategy is:

  • 3 — Keep three copies of important data
  • 2 — Store them on two different types of media or storage
  • 1 — Keep one copy somewhere separate from your primary device

Most important: A backup only helps if you can actually restore your files. Check your backups periodically.

Physical Security

Cybersecurity Starts with the Device Itself

Digital security can't help much if someone can simply walk away with your device.

Protect Your Devices

  • Lock your screen when stepping away.
  • Use a PIN, password, or biometric lock.
  • Don't leave your laptop or phone unattended in public.
  • Keep devices somewhere secure when you're not using them.
  • Consider tracking features such as Find My or Find My Device.
  • Don't let strangers use your unlocked device.
  • Be cautious when charging devices through unfamiliar equipment.

Lost Your Device?

If a device is lost or stolen, act quickly:

  1. Try to locate it using its tracking feature.
  2. Lock it remotely if possible.
  3. Change important account passwords.
  4. Report the device as lost or stolen when appropriate.
  5. Contact your school, workplace, or service provider if necessary.

Device Security Checklist

Before you move on, check your devices:

  • Automatic updates are enabled
  • Security software is active and updated
  • I only download software from trusted sources
  • I know how to identify suspicious downloads
  • I use public Wi-Fi carefully
  • My important files are backed up
  • My devices require a PIN, password, or biometric to unlock
  • I know how to locate or remotely lock my devices

Secure Your Device. Protect Your Data.

A secure device is built through small habits: keep it updated, be careful about what you install, back up what matters, and protect the device itself.
